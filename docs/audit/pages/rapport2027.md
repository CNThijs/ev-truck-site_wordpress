## Interactive behaviour

- Bare /rapport2027 client-side redirects to ?utm_source=trend_report&utm_medium=DM&utm_campaign=tr2027&utm_term=form-access.
- /rapport2027/download and /rapport2027/<code> redirect to the same page with utm_term=download / utm_term=<code>.
- Lead form has two views: "with code" (allowlisted campaign code → only email needed) and "no code" (name + company + email). Max failed-code attempts tracked in sessionStorage; then user must choose "no code" path.
- GA events: view, cta click, form start, form submit, report download.
- Shared layout behaviour: see `_shared-layout.md`.
