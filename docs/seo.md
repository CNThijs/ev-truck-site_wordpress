## Rules in code (`inc/seo.php`)

- **Environment flag.** `WP_ENVIRONMENT_TYPE` (set in `wp-config.php` or the server environment). Anything but `production` and `local` serves `noindex, nofollow` (meta and `X-Robots-Tag`) and `Disallow: /` in robots.txt. WordPress treats an unset value as production, so **a staging copy must set it** (`define( 'WP_ENVIRONMENT_TYPE', 'staging' );`). DDEV sets `local`, which is indexable on purpose (it is not on the internet) so the checks run against it.
- **No indexable duplicates.** Search results, page 2 and later of News and category lists: `noindex, follow`. Attachment pages redirect. Tag and author and date archives do not exist or are noindex. The News canonical is its own URL.
- **Headings.** One h1 per page (the page's title band). Cards and FAQ questions are h2. Imported posts start their headings at h2. The block editor warns, live while typing, about an h1 in the text, a skipped heading level, link texts like "here" and images without alt text (`inc/editor-checks.php`).
- **Share image.** `assets/img/social-default.png` (1200 × 630, logo on the dark green) is used for pages and posts without a featured image. To make another: put a 1200 × 630 background and the logo in an HTML page and take a screenshot with Chrome (`--headless --window-size=1200,630 --screenshot`). Posts use their featured image; use landscape images.
- **robots.txt.** WordPress generates it: sitemap line (`/sitemap_index.xml`), `/wp-admin/` blocked, internal search blocked.
- **Root redirect.** `/` answers 302 to `/en/`: Polylang sends it before the theme loads. For a 301 add one line to `.htaccess` on the server: `RedirectMatch 301 ^/$ /en/`.

## Checks

| Command                                   | What                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm run check:seo -- <url> --production` | Crawls both language homes, the sitemaps (each language file lists only its own URLs, every entry has `lastmod`, no URL twice) and internal links: titles and descriptions (missing, duplicate, long), canonical, duplicate tags, Open Graph, h1 count, structured data (Organization, WebSite, WebPage, BreadcrumbList, BlogPosting with its properties), alt attributes, broken internal links, indexability. `--staging` expects noindex everywhere. Without a flag the indexing check is skipped. |
| `npm run check:hreflang`                  | Reciprocal hreflang, self links, x-default.                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `npm run check:redirects`                 | Every row of `docs/redirects.csv`: status, one hop, target answers 200. PROVISIONAL rows are reported, not failed.                                                                                                                                                                                                                                                                                                                                                                                    |
| `npm run test:blog`                       | Post checks, including the heading and link text helper.                                                                                                                                                                                                                                                                                                                                                                                                                                              |

The checks run against the local site as they are. To test the staging protection set `WP_ENVIRONMENT_TYPE=staging` in `.ddev/config.yaml`, `ddev restart`, run `npm run check:seo -- <url> --staging` and set it back to `local`.

## Launch checklist

0. **Root redirect and old addresses:** the redirect block generated by `node bin/build-redirects-htaccess.mjs` (it contains `/` → `/en/` as a 301, http/www → https, and every row of `docs/redirects.csv`; see `docs/launch-runbook.md`) goes into `.htaccess` on STRATO. The older single-line version: add `RedirectMatch 301 ^/$ /en/` to `.htaccess` on STRATO (after the WordPress block's `# END WordPress` is fine; before it is safer) so `/` is a 301, not Polylang's 302. Then change the `/` row in `docs/redirects.csv` to 301 and check with `npm run check:redirects -- https://chargenet.energy`.
1. `WP_ENVIRONMENT_TYPE` is **not** set to anything but `production` on the live site (view source: no `noindex`; `https://chargenet.energy/robots.txt` has no `Disallow: /`). Staging has it set.
2. `npm run check:seo -- https://chargenet.energy --production`, `check:hreflang`, `check:redirects` all pass against the live site.
3. Settings → Reading: "Discourage search engines" is off.
4. **Google Search Console**: add `https://chargenet.energy` as a domain property (DNS TXT record), submit `https://chargenet.energy/sitemap_index.xml`, use URL Inspection on the home page, one Dutch page and one post.
5. **Bing Webmaster Tools**: import the site from Search Console, or add it and verify (DNS), submit the sitemap.
6. Open the live home page in the Rich Results Test and check the Organization data.
7. After a week: Search Console → Pages, look for "Not found (404)" lists from old URLs; add rows to `docs/redirects.csv` and `inc/redirects.php`. Check which queries bring visitors and adjust `content/seo.php`.
8. Update the Google Business and LinkedIn pages to link to `https://chargenet.energy/`.
